# Скачать игру

- [Играть: ZIP с автономным HTML](HIVEBREAK_REFORGED_v080.zip?raw=true).
- [Исходный проект: ZIP](HIVEBREAK_REFORGED_v080_SOURCE.zip?raw=true).

Нажмите ссылку или откройте ZIP на GitHub и выберите **Download raw file**.
Распакуйте игровой архив и откройте `HIVEBREAK_REFORGED_v080.html` в браузере.
Установка и подключение к интернету для игры не требуются.

Архивы созданы из проверенной версии 0.8.0 (исходники на коммите `452b6eb`).
Для новой сборки используйте `python3 build_portable.py`; результаты появятся
в локальном каталоге `dist/`.
