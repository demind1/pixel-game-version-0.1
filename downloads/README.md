# Скачать игру

## Версия 1.0 — настоящий 3D-рендер

- [Скачать игру ZIP](HIVEBREAK_REFORGED_v100.zip?raw=true).
- [Скачать исходный проект 1.0](HIVEBREAK_REFORGED_v100_SOURCE.zip?raw=true).
- [Скриншоты и результаты проверок](../docs/VERSION_1_0.md).

Нажмите ссылку или откройте ZIP на GitHub и выберите **Download raw file**.
Распакуйте игровой архив и откройте `HIVEBREAK_REFORGED_v100.html` в браузере.
Установка и интернет для игры не требуются. «Настройки → Графика» позволяют
выбрать качество, отражения и свечение. Для максимальной детализации выберите
«Максимум»; на слабом GPU — «Баланс» или «Эконом».

Контрольные суммы и исходный коммит: [release-v100.json](release-v100.json).
Для самостоятельной сборки: `npm ci`, затем `npm run build`.
