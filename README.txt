КСЕНОМОРФ: ПРОРЫВ УЛЬЯ — РУССКАЯ ВЕРСИЯ v0.7.1
==================================================
ИГРАТЬ МОЖНО БЕЗ ИНТЕРНЕТА

ВАРИАНТ 1. Откройте автономный файл HIVEBREAK_RU_v071.html.
Изображения, шрифты, аудио и код уже встроены в один файл.

ВАРИАНТ 2. Распакуйте архив целиком и запустите index.html.
Не переносите index.html отдельно от game.js, style.css и папки assets.

КЛАВИАТУРА (игрок 1)
WASD или стрелки — ходить и менять глубину сцены.
J — комбо когтями (J→J→J); K — тяжёлый удар хвостом.
J→J→K — мощный завершающий удар.
L — обычная уникальная способность класса (35 энергии).
U — усиленная классовая способность (80 энергии):
    Drone — Acid Claw, Warrior — Predator Slam,
    Runner — Ripper Combo, Praetorian — Armored Counter.
Space — прыжок (J и K в воздухе активируют воздушные атаки).
Shift — уклонение; E — захват/бросок.
Esc — пауза; F — полный экран; M — звук вкл/выкл; F3 — debug.
В настройках: Q/E — смена вкладки, стрелки — выбор и изменение значений.

ГЕЙМПАД (игрок 2 или 1 в одиночном режиме)
Левый стик/D-pad — движение, X — когти, Y — хвост, B — класс-атака,
A — прыжок, RB — рывок, LB — захват, LT — ультимативный приём,
Start — подключиться вторым игроком на экране выбора или пауза.
Схема основана на стандартном Gamepad API / XInput-совместимом контроллере.

КООПЕРАТИВ
В меню выберите «КООП», на экране выбора нажмите Start на геймпаде.
После подключения выберите класс 2P и начните игру.
Один экран, независимые HP/энергия, общие враги и камера.

НАСТРОЙКИ
GAMEPLAY: сложность, умеренность кровавых эффектов LOW/NORMAL/HIGH,
          цифры урона, сброс.
GRAPHICS: Pixel 3D Scenery, частицы, окружение, shake, flashes,
          scanlines, контраст HUD.
AUDIO: громкость музыки и эффектов, пользовательский оригинальный
       Level 01 MP3 (или новые синтезированные музыкальные темы).

ДОБАВЛЕНО В v0.7
- Промежуточные позы из исходного спрайтового листа и процедурные
  анимационные варианты для солдат и трёх боссов.
- 3 новых противника: медик, тяжёлый пулемётчик, летающий дрон.
- 4 усиленных классовых приёма, новые завершающие комбо.
- Пиксельный bitmap font, новые настройки и элементы UI.
- Стилизованные эффекты попаданий, умеренная аркадная кровь.
- Программная 3D-проекция для небольших голограмм, турбин,
  декоративных объектов и корпуса дрона (без тяжёлого движка).
- Новые уникальные декорации для трёх секторов.
- 6 новых оригинальных синтезированных музыкальных лупов.

ОГРАНИЧЕНИЯ
- Это работающая расширенная сборка, но не коммерческий production release.
- Промежуточные анимации созданы деформацией и оптическим потоком между
  исходными предоставленными кадрами; полноценно вручную нарисованные
  новые спрайтовые наборы для всех классов не созданы.
- Проверки включали статический JavaScript и симуляцию игры с подменённым
  Canvas; реальное воспроизведение в браузере этой итерации не подтверждено
  из-за административной блокировки браузерной автоматизации в среде.
- Свою производительность и работу конкретного DualSense проверьте на ПК.

ПРАВА НА РЕСУРСЫ
Характерные образы ксеноморфов и логотипы франшизы могут быть
защищены правами третьих лиц. Присланные изображения и музыка
используются здесь в рамках личного прототипа; для публичного
распространения/монетизации необходима проверка прав.


КАК ЗАПУСТИТЬ НА WINDOWS
1. Скачайте архив HIVEBREAK_RU_v071.zip — он содержит один HTML-файл и инструкцию.
2. Нажмите по ZIP правой кнопкой мыши → «Извлечь всё».
3. Дважды нажмите на файл HIVEBREAK_RU_v071.html.
4. Если открывается код — правая кнопка мыши → «Открыть с помощью» → Opera/Chrome/Edge.
Ничего устанавливать не нужно. Интернет после скачивания не требуется.
