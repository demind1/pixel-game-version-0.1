# XENOMORPH: HIVEBREAK — Ultimate Arcade Remaster v0.7

## Что изменилось относительно v0.6

### Художественные материалы и анимация
- Введён новый спрайт-атлас `xeno_animation_10x4.png`: 10 кадров на четыре ряда. Промежуточные кадры получены **оптическим потоком** из первоначальных кадров 4×4; это дополненная анимация, но **не** вручную нарисованные уникальные кадры.
- `marine_motion_8x4.png`: варианты ожидания, ходьбы, огневой отдачи и реакции на удар, вычисленные деформациями предоставленного спрайта.
- Три разных визуальных босса: `boss_guardian_8x3.png`, `boss_siege_8x3.png`, `boss_queen_8x3.png`; в каждом 24 программно сгенерированных варианта исходного арта. Это важный шаг относительно прежней одной картинки, но анимация всё ещё не уровня художника-аниматора.
- Внедрён bitmap-шрифт на основе системного monospace, растеризованный в фиксированной сетке для масштабирования ближайшим соседом.
- Каждому сектору добавлены собственные декорации: лабораторные камеры, армейские стеллажи, реакторные кольца, органические структуры.
- Минимальные **настоящие 3D-полигоны**, вычисляемые JavaScript-проекцией и отрисовываемые Canvas: голограммы, кубические модули, корпус охранного дрона. Основная игра остаётся 2.5D.

### Механика
- Введены **3 новых противника**: `medic` (лечение союзников), `gunner` (подготавливаемые очереди и уязвимость после них), `drone` (подвижная летающая единица).
- Все три уровня используют новые сочетания типов врагов.
- Для каждого из четырёх классов создан отдельный усиленный приём на `U`: Acid Claw, Predator Slam, Ripper Combo, Armored Counter (энергия 80).
- Лёгкая серия с последующим тяжёлым ударом даёт новый `finisher`; у Ripper Combo многоударная активная фаза.
- Боссы 1–3 имеют отдельные изображения и дополнительные приёмы: рывок, бронированный таран, призыв подкреплений.
- При попаданиях добавлены умеренные пиксельные кровавые/искровые эффекты, декали и настраиваемая интенсивность LOW/NORMAL/HIGH.
- Во время стрельбы у ряда солдат вылетают гильзы.

### Интерфейс и музыка
- 3 вкладки настроек: Gameplay, Graphics и Audio.
- Включение/отключение Pixel 3D, качество частиц, ambient, контрастность HUD, кровь, цифры урона и звуковые настройки.
- Шесть **оригинально синтезированных** OGG-лупов — три сектора и три босса (18–34 секунды каждый). По желанию можно вернуть загруженный пользователем исходный MP3 для первого сектора.
- Переходы между мелодиями с мягким затуханием.
- Автономный HTML с включёнными ресурсами и обычная проектная структура.

## Проверки этой итерации
- `node --check game.js` — успешно.
- `node test_engine.js` — успешно с имитированным DOM/Canvas: меню, симуляция 60 Гц, все четыре игровых класса, все десять типов противников, все три уровня, переходы фаз 1→2→3 для каждого босса, смерть босса, пауза, совместная игра с Gamepad API и независимым вводом игрока 2.
- `ffprobe` успешно прочитал все шесть музыкальных файлов.
- Автономная HTML-сборка содержит все 21 необходимых дополнительных графических/звуковых ресурса в виде data URI.

### Что пока не подтверждено
- Тест реального рендеринга и воспроизведения в браузере новой итерации: локальная политика Chromium блокирует любые локальные навигации в доступной тестовой среде. Поэтому нельзя утверждать, что браузерный E2E-прогон этой версии прошёл.
- Стабильные 60 FPS на разных физических ПК и реальный DualSense тоже не тестировались.
- Новые sprite-позы созданы из исходного арта вычислительно; полноценную ручную покадровую анимацию/уникальных 3D-моделей всех персонажей ещё надо производить отдельно.
