# Ксеноморф: Прорыв улья — Reforged 0.8

Ремастер предоставленной игры HIVEBREAK RU v0.7.1. Основа — Canvas 2D,
beat ’em up с глубиной арены, четыре класса и локальный кооператив.
Все исходные изображения и музыкальные темы сохранены в истории Git.

## Играть без установки

Распакуйте `HIVEBREAK_REFORGED_v080.zip` и откройте
`HIVEBREAK_REFORGED_v080.html` в Chrome, Edge, Firefox или Opera.
Изображения, шрифт, музыка и код встроены: подключение к сети не требуется.
Первое нажатие включает звук согласно правилам браузера.

Исходную версию можно открыть через `index.html` рядом с `game.js`,
`style.css` и всей папкой `assets`. Для разработки предпочтителен HTTP:

```sh
cd /workspace/pixel-game-version-0.1
python3 -m http.server 8080
```

Откройте порт 8080 средствами своей среды. `npm start` запускает тот же сервер.
Игра не требует `npm install`, сборщика, сервера API или ключей доступа.

## Управление

| Действие | Клавиатура | Стандартный геймпад |
| --- | --- | --- |
| Движение | WASD / стрелки | Левый стик / крестовина |
| Когти / комбо | J | X |
| Тяжёлая атака | K | Y |
| Способность | L | B |
| Прыжок | Space | A |
| Рывок | Shift | RB |
| Захват / бросок | E | LB |
| Суперприём | U | LT |
| Пауза | Esc | Start |
| Полный экран | F | Через настройки |
| Звук | M | Через настройки |

Русская раскладка работает на тех же физических клавишах. Клавиши можно
изменить в «Настройки → Клавиши». Q/E переключают вкладки, стрелки меняют
параметр, Enter начинает переназначение, Esc отменяет. Параметры и рекорды
сохраняются локально в браузере. В кооперативе клавиатура управляет первым
игроком, один геймпад — вторым: выберите «Кооператив» и нажмите Start на
экране выбора. Физический геймпад в облаке не проверялся; проверен Gamepad API.

## Что изменилось

- Новый читаемый монохромный атлас с кириллицей, Ё/ё и точным порядком символов,
  целочисленное масштабирование, новый HUD и четыре вкладки настроек.
- Ввод по `KeyboardEvent.code`, резервная поддержка русских символов, буфер
  команд 125 мс, нормализация диагонали, направленный рывок, сброс при потере
  фокуса и отключении геймпада.
- Исправлены укус в захвате, освобождение пленника, расход энергии,
  двойные попадания, контратака, высота прыжков и границы атак с перемещением.
- 704 кадра четырёх классов: сохранённые голова/корпус исходного спрайта и
  заново поставленные конечности, когти, хвост и броня. Это гибридные кадры
  с отдельными позами, без оптической интерполяции. 56 поз морпеха и 72 кадра
  новых боссов. Генераторы находятся в `tools`.
- Шесть миссий: лаборатория, военный комплекс, реактор, криогенный склад,
  орбитальный док и центральный улей. 30 волн, 15 типов врагов, включая
  инженера, штурмовика, тяжёлого андроида и два элитных типа.
- Шесть боссов с тремя фазами, предупреждениями об атаках, ограниченным
  подкреплением и разными наборами приёмов. Перезарядка врагов, ограничение
  одновременных атак и восстановление недопустимых позиций без удаления врагов.
- Различные декорации шести секторов, параллакс, умеренные настоящие 3D-сетки
  с программной проекцией и плоской заменой при выключении объёмных эффектов.
- Шесть новых оригинальных стереотем, многослойные шумовые/тональные эффекты,
  лимитер, ограничение голосов, плавные переходы и общая громкость.

## Проверить и собрать

```sh
npm test
python3 tests/assets.py
python3 tests/browser_regression.py
python3 build_portable.py
python3 tests/browser_regression.py --portable dist/HIVEBREAK_REFORGED_v080.html
```

`npm test` использует только Node.js. Браузерные тесты требуют Python,
Playwright и Chromium; проверки ресурсов — Pillow. Точные версии остальных
инструментов генерации записаны в `requirements-dev.txt`.
В облачной песочнице запуск Chromium может требовать разрешённого запуска
вне песочницы; сама игра не требует привилегий.

Сборщик на стандартной библиотеке Python создаёт HTML и ZIP в `dist/`.
Старые имена `tests/smoke.py`, `tests/qa_runtime.py`, `test_browser_v07.py`
сохранены как входы в актуальную проверку с реальными ресурсами.
`patch_*.py` — исторические одноразовые миграции v0.7; повторно их не запускайте.

Полные результаты и ограничения: [docs/VALIDATION.md](docs/VALIDATION.md).
Исходное задание: [docs/REMASTER_BRIEF_RU.md](docs/REMASTER_BRIEF_RU.md).

## Границы этой версии

Логическая сцена остаётся 480×270, чтобы сохранить геометрию исходной игры.
Проверено размещение окна в 720p/1080p/1440p/2160p и 4:3, но это не нативный
4K-рендер и не переход на 640×360. На 4K применяется целый масштаб 7× с полями.
Новые позы сочетают исходную графику и программно созданные конечности:
полностью ручная перерисовка всех персонажей не выполнена. Звуковые файлы
проверены декодированием и измерением сигнала; художественная оценка микса
на реальных колонках/наушниках ещё нужна. Полное прохождение человеком и
баланс финальных секторов требуют отдельного игрового тестирования.

Весь интерфейс русскоязычный, однако централизация текста пока частичная:
словарь `RU`, определения классов/миссий/настроек и ряд игровых сообщений.
Геймпад использует стандартное отображение Gamepad API; произвольная
перепривязка кнопок геймпада, вибрация и сенсорное управление не реализованы.

Условия исходных материалов см. в `README.txt`. Новый шрифт — DejaVu Sans
Mono, условия в `assets/FONT_LICENSE.txt`; происхождение новых музыкальных
тем и уровни сигнала — `assets/reforged_music.json`.
