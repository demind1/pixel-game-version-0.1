# Ксеноморф: Прорыв улья — REFORGED 1.1

Обновление 3D-персонажей, движения и боя. Четыре класса, шесть секторов,
30 волн, 15 типов врагов и локальный кооператив сохранены.

## Скачать и играть

Откройте [раздел downloads](downloads/) в ветке `feature/hivebreak-character-overhaul`.
Скачайте `HIVEBREAK_REFORGED_v110.zip` кнопкой **Download raw file**,
распакуйте и откройте `HIVEBREAK_REFORGED_v110.html` в Chrome/Edge/Opera.
Код, Three.js, модели, картинки, музыка и шрифт встроены. Интернет для игры
не нужен. Первое нажатие разрешает звук по правилам браузера.

## Что изменилось в 1.1

- Пять настоящих GLB-моделей из Blender: четыре разных ксеноморфа и морпех.
  Цельная деформируемая кожа, удлинённые черепа, рёбра, наружная и внутренняя
  челюсти, отдельные фаланги, когти, броня, лицо и снаряжение.
- По 53 кости и 20 анимаций у ксеноморфов; 42 кости и 23 анимации у морпеха.
  Разные траектории когтей, удар хвостом, подбрасывание, прыжок, рывок,
  парирование, захват, бросок, реакция на удар, падение, стрельба и перезарядка.
- Смешивание поз и шаг по пройденному расстоянию; удержание опорных стоп
  через двухзвенный IK. Хвост из 17 костей получает инерцию и ограничение пола.
- Тяжёлые враги сильнее сопротивляются отбрасыванию. Мягкие контакты тел
  препятствуют наложению; направление рывка и воздушные атаки сохраняются.
- Снаряжение различает роли: щит, медик, огнемёт, тяжёлый пулемётчик,
  андроиды и экзоскелет. У шести боссов сохранены отдельные силуэты;
  подготовка и завершение их атак связаны с игровой симуляцией.
- Новые normal maps и материалы хитина, ткани, кожи и брони.
  Освещение, тени, свечение и настоящие зеркальные отражения пола сохранены.
- 12 новых оригинальных инструментальных рок-тем с перегруженными
  power chords, басом и барабанами. «Настройки → Аудио → Стиль музыки»
  переключает рок и прежнюю электронику.

Скриншоты, методы проверки и ограничения: [отчёт 1.1](docs/CHARACTER_OVERHAUL_1_1.md).
Это авторская стилизованная 3D-графика; фотореализм и моушн-капчер не заявляются.

## Управление

| Действие | Клавиатура | Стандартный геймпад |
| --- | --- | --- |
| Движение | WASD / стрелки | Стик / крестовина |
| Комбо когтями | J | X |
| Хвост / тяжёлая атака | K | Y |
| Способность класса | L | B |
| Прыжок | Space | A |
| Направленное уклонение | Shift | RB |
| Захват / бросок | E | LB |
| Суперприём | U | LT |
| **Парирование** | **Q** | **RT** |
| **Добивание** | **R** | **Нажать правый стик** |
| Пауза | Esc | Start |
| Полный экран / звук | F / M | Настройки |

Русская раскладка работает на тех же физических клавишах.
«Настройки → Клавиши» позволяют изменить привязки. Q/E переключают вкладки,
стрелки меняют значения, Enter начинает переназначение, Esc отменяет.
Параметры и рекорды сохраняются локально.

**Новые приёмы:** J → K подбрасывает цель; J → J → K завершает комбо.
Парирование Q действует 10 тиков, защищает спереди и открывает усиленный
ответ на 1,5 секунды. Следующее попадание наносит ×1,7 урона.
Добивание R доступно перед врагом с ≤25% здоровья, стоит 20 энергии,
восстанавливает 18 здоровья при успешном убийстве и имеет перезарядку.

Кооператив: выберите соответствующий пункт, нажмите Start на геймпаде на
экране выбора. Клавиатура управляет первым игроком, геймпад — вторым.

## Графика и производительность

Вкладка «Графика»: включение 3D, качество «Эконом / Баланс / Максимум»,
отражения, свечение, частицы, тряска, вспышки и полный экран.
«Эконом» сохраняет настоящие 3D-модели, отключая дорогостоящие тени,
свечение и зеркальный проход. «Максимум» повышает разрешение 3D до ширины
окна с пределом 2560 пикселей. Интерфейс масштабируется отдельно до 3840×2160.
Это не обещание нативной 4K-отрисовки сцены на любом устройстве.

На слабом или программном GPU уменьшите качество. В облаке использован
SwiftShader, поэтому его частота кадров не характеризует обычную видеокарту.
Подробные результаты и ограничения: [docs/CHARACTER_OVERHAUL_1_1.md](docs/CHARACTER_OVERHAUL_1_1.md).

## Разработка и проверки

Готовая игра уже включает собранный рендер. Для запуска исходников:

```sh
python3 -m http.server 8080
```

Откройте порт 8080 средствами среды. `npm start` запускает тот же сервер.
Переустановка зависимостей нужна только при изменении исходника 3D-модуля:

```sh
npm ci
npm run build:renderer
npm test
python3 tests/assets.py
python3 tests/browser_regression.py
python3 tests/browser_10.py
npm run build
python3 tests/browser_10.py --portable dist/HIVEBREAK_REFORGED_v110.html
python3 tests/release_smoke.py dist/HIVEBREAK_REFORGED_v110.html
```

`src/renderer3d.js` — исходник 3D-системы; `vendor/renderer3d.js` — автономный
IIFE-бандл, работающий и в одном HTML. `game.js` — игровая симуляция и UI.
Python-сборщик использует стандартную библиотеку; браузерные проверки требуют
Playwright и Chromium. Генераторы и дополнительные зависимости описаны в
`requirements-dev.txt`. Команды проверки внутри строгой облачной песочницы
могут требовать разрешённого запуска Chromium вне неё.

Зависимости закреплены в `package-lock.json`. Three.js распространяется по MIT:
[vendor/THREE_LICENSE.txt](vendor/THREE_LICENSE.txt). Новые 3D-модели,
окружения и процедурные материалы созданы кодом проекта. Исходные ресурсы
не удалены; условия исходных картинок/музыки см. в `README.txt`, условия
пиксельного шрифта — в `assets/FONT_LICENSE.txt`.

Для пересоздания моделей нужен Blender 4.3+, для музыки — NumPy, SciPy и ffmpeg:

```sh
blender --background --factory-startup --python tools/build_characters.py
python3 tools/create_rock_music.py
npm run build
```

Готовые GLB/OGG включены в репозиторий: Blender и генераторы не требуются
для обычного запуска и упаковки. `src/character-motion.js` управляет клипами,
опорой стоп и хвостом; `src/character-equipment.js` — скелетным снаряжением.
Исходные задания сохранены в [основном промте](docs/REMASTER_BRIEF_RU.md) и
[дополнении о 3D-персонажах](docs/NEXT_GEN_BRIEF_RU.md).
